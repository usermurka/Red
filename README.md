# Красная книга Омской области — интерактивная карта

Веб-приложение с интерактивной картой мест встреч видов, занесённых в Красную книгу Омской области. Работает полностью на стороне клиента (HTML + CSS + JavaScript), без серверной части и сборки. Данные о видах хранятся в JSON-файлах, пользовательские отметки — в `localStorage`.

## Возможности

- **Интерактивная карта** с маркерами наблюдений (5 вариантов карт на выбор).
- **Каталог видов** по категориям: животные, растения, лишайники, грибы (385 видов с изображениями и карточками).
- **Два режима работы**: режим гостя (просмотр) и режим разработчика (добавление/редактирование маркеров, импорт/экспорт данных).
- **Полевой дневник** — создание записей с несколькими точками и фотографиями наблюдений.
- **Игры и викторины** для изучения видов:
  - 🎲 Викторина (вопросы с таймером);
  - 🧩 Найди пару;
  - 🃏 Мемори.

## Запуск

Приложение статическое. Достаточно открыть `index.html` в браузере.

> **Примечание:** часть функционала (загрузка `data/species/*.json` через `fetch`) требует HTTP-протокола. Для запуска локального сервера:
>
> ```bash
> # Python
> python -m http.server 8000
>
> # или Node.js
> npx serve .
> ```
>
> Затем откройте http://localhost:8000

## Работа с данными

### Импорт нового вида (`scripts/import.py`)

1. Поместите описание вида в `inbox/data.txt` (18 обязательных полей) и картинку рядом.
2. Запустите:
   ```bash
   python scripts/import.py          # обычный запуск
   python scripts/import.py --force  # пропустить защиту от дубликатов
   ```
3. Скрипт валидирует данные, проверяет защиту от повторного импорта (id + хэш текста), записывает `data/species/{id}.json` и переносит изображение в `img/species/{id}.png`.

После каждого цикла скрипт ждёт нажатия Enter для импорта следующего вида; выход — Ctrl+C.

### Заполнение status_text (`scripts/fill_status_text.py`)

```bash
python scripts/fill_status_text.py
```

Обходит виды в порядке систематики (как в `js/species.js`). Управление:

| Действие | Клавиши |
|---|---|
| Сохранить и перейти к следующему виду | текст + Enter |
| Пропустить вид | Enter (пустая строка) |
| Вернуться к предыдущему виду | `u` + Enter |
| Выйти (прогресс сохраняется) | `q` + Enter |

## Требования

- Любой современный браузер (Chrome, Firefox, Edge, Safari).
- Python 3 — только для скриптов импорта и заполнения данных (`scripts/`).
